# P.9 — Ruff

## Purpose

Ruff is a linter and formatter for Python.

---

## Responsibilities

- Detect errors.
- Improve code quality.
- Remove unused imports.
- Enforce coding standards.

---

## Commands

ruff check .

ruff check . --fix

ruff format .

## Check the installation
ruff --version

## Run Ruff
ruff check .
## Automatically fix issues
ruff check . --fix
## Format the code
ruff format .

# Pydantic

## Purpose

Pydantic validates and parses data using Python type hints.

---

## Features

- Validation
- Type conversion
- Error handling
- Serialization
- Schema generation

---

## Workflow

Input Data
    ↓
Validation
    ↓
Type Conversion
    ↓
Python Object

---

## Common Usage

- FastAPI Request Models
- FastAPI Response Models
- Agent State
- Tool Input Schemas
- Structured LLM Outputs
